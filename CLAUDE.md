# Padelicense Shop — Next.js Frontend

## Conventions
- Named exports only (`export const Component`), no default exports
- Components use `type` (not `interface`) for props
- Props passed as single argument: `(props: MyProps) => { const { ... } = props; }`
- Components grouped in folders: `Component/Component.tsx`, `Component.stories.ts`, `Component.test.tsx`
- Central index at `components/ui/index.ts` for re-exports
- Queries colocated with pages in `_queries/` folders, or in `_hooks/` for client components
- GraphQL Codegen generates types — never write types manually for API data
- Front tests focus on business logic (conditional rendering, formatting, states), not trivial rendering
- No `any` — use `unknown` with type guards or proper types instead
- No deep relative imports (max 3 levels `../../../`) — use `@/` alias instead

## i18n
- Supported locales: en, fr, nl (default: en)
- All pages under `src/app/[locale]/`
- No hardcoded user-facing text — always use translation keys
- Async Server Components: `getTranslations()` from `next-intl/server`
- Non-async Server Components / Client Components: `useTranslations()` from `next-intl`
- Use `Link` from `@/i18n/navigation` (not `next/link`) for locale-aware links
- Format numbers/dates with locale: `Intl.NumberFormat(locale, ...)`, never hardcode `"en-US"`
- Translation files in `messages/{locale}.json`
- Product names, descriptions, slugs are NOT translated (they come from the DB)
- Middleware in `src/proxy.ts` handles locale detection from browser `Accept-Language`

## Stack
- Next.js 16 App Router, Tailwind 4, Apollo Client 4
- next-intl for internationalization
- Storybook 10 for design system documentation
- Vitest + React Testing Library for unit tests
- Playwright for E2E tests
- GraphQL Codegen for type generation
- Prettier for formatting

## Architecture
- `src/app/[locale]/` — pages (App Router), Server Components by default
- `src/components/ui/` — design system (reusable across pages)
- `src/lib/` — technical config (Apollo, utils)
- `src/i18n/` — routing, navigation, request config
- `src/gql/` — auto-generated by Codegen (do not edit)
- `messages/` — translation files (en.json, fr.json, nl.json)
- `_queries/` — GraphQL queries colocated with pages
- `_hooks/` — hooks for client components

## API
- Server Components use `query()` from `@/lib/apollo` (public, no auth)
- Client Components use hooks with `useSuspenseQuery` via ApolloProvider (with auth)
- API runs on port 3000, frontend on port 3001
